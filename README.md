# 📊 Vrinda Store Annual Report 2022 – Excel Data Analysis

## 📌 Project Overview

This project is an **Excel Data Analysis and Dashboard project** based on the **Vrinda Store Annual Report 2022**.

The dashboard analyzes sales, orders, customer demographics, order status, sales channels, and top-performing states to understand the store's overall business performance.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze monthly sales and order trends
- Compare sales between men and women
- Analyze order status
- Identify top-performing states
- Understand sales by age and gender
- Analyze orders across different sales channels
- Create an interactive and easy-to-understand Excel dashboard

---

## 📊 Dashboard Insights

The dashboard contains the following visualizations:

### 1. Orders vs Sales
Shows the monthly relationship between:
- Total Sales
- Number of Orders

### 2. Sales: Men vs Women
Shows the percentage of sales contributed by:
- Men – 36%
- Women – 64%

### 3. Order Status
Shows the distribution of orders based on their status:
- Delivered
- Cancelled
- Returned
- Refunded

### 4. Top 5 States in Sales
Shows the top-performing states based on sales.

Top states include:
- Maharashtra
- Karnataka
- Uttar Pradesh
- Telangana
- Tamil Nadu

### 5. Age vs Gender
Compares sales/orders across different age groups:
- Adult
- Senior
- Teenager

for both men and women.

### 6. Orders: Channels
Shows the percentage of orders received through different channels, such as:
- Amazon
- Myntra
- Flipkart
- Ajio
- Meesho
- Nalli
- Others
